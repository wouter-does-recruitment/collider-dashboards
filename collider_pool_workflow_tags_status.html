Draft operating system for DeepTech Founders Radar and Talent Pool Not Founders

Draft
For Consuelo discussion
Principle
Keep tags durable, keep status in workflow
Tags should describe stable search information. Temporary things like active, pending, replied, current candidate or follow-up timing belong in Manatal stage, notes, tasks or date fields.

Tag proposal

Fit tags

Fit = what type of future role/search someone could be relevant for. This is not necessarily what they have already done.

Fit - CEO / Co-FounderFit - Commercial Co-Founder / CBOFit - COO / Operating Co-FounderFit - CTO / Technical Co-FounderFit - CSO / Scientific Co-FounderFit - AdvisorFit - Referral / EcosystemFit - Investor / Fund

Sector tags

Sector = market/domain relevance.

Sector - BiotechSector - MedTechSector - Medical DevicesSector - Digital Health / SaMDSector - Female HealthSector - Energy / GridSector - SpaceTechSector - Advanced MaterialsSector - AI / DataSector - FoodTech

Signal tags

Signal = what someone has actually proven.

Signal - Founder-CEO experienceSignal - Founder experienceSignal - CEO / P&L experienceSignal - Corporate to founderSignal - Fundraising privateSignal - Fundraising public / grantsSignal - Tech transferSignal - IP / licensingSignal - CommercialisationSignal - Venture building

History / Outcome tags

Only durable Collider-specific context. No "current candidate" or nurture timing as tags.

Affiliation - Collider founderHistory - Previous Collider candidateHistory - Staff interviewHistory - MatchmakingOutcome - Placed founderHistory - Do not contact
